# 🎸 Florence Connect

Aplikasi web pendaftaran anggota UKM Musik Florence berbasis React + Node.js.

## 📋 Deskripsi

Florence Connect adalah sistem pendaftaran digital untuk UKM Musik Florence yang memungkinkan calon anggota mendaftar secara online, memilih jadwal latihan dan divisi, serta admin dapat mengelola data pendaftar melalui dashboard.

## 🛠️ Tech Stack

**Frontend:**
- React 18 + Vite
- Tailwind CSS
- React Router DOM
- Axios
- Lucide React

**Backend:**
- Node.js + Express
- MySQL2
- JWT Authentication
- Bcrypt

**Database:**
- MySQL

## 🚀 Fitur

- ✅ Register & Login dengan JWT
- ✅ Pilih jadwal latihan (6 hari: Senin–Sabtu)
- ✅ Pilih divisi (Gitar, Piano, Drum, Bass, Vokal, Manajemen Band)
- ✅ Status pendaftaran real-time
- ✅ Admin dashboard dengan statistik
- ✅ Filter & search data pendaftar
- ✅ Update status pelamar
- ✅ Responsive mobile & desktop
